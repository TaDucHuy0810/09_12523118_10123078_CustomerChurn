# Dataset package

`dataset.zip` contains the local `telco_churn.csv` used by this project. The source is the IBM Telco Customer Churn sample hosted at Kaggle:

- https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- Source file: `data/telco_churn.csv` (7,043 rows, semicolon-separated)
- Target: `Churn Label` (`No` / `Yes`)

Kaggle currently displays the notice “Data files © Original Authors”; an explicit open redistribution license was not confirmed. This archive is included for the coursework workflow, but verify the current Kaggle terms and obtain permission before redistributing outside the assignment.

See the repository-root `DATA.md` for the complete 20-feature dictionary, cleaning rules, target distribution, and observed numeric ranges.
